Вызовите `extract_text(file_path)` — передайте локальный путь к файлу PDF, TXT или DOCX. Функция возвращает строку в виде обычного текста. Если файл отсутствует, пуст или не поддерживается, она выдаст понятное сообщение об ошибке.







Call `extract_text(file_path)` — pass the local path to a PDF, TXT, or DOCX file. It returns a plain text string. If the file is missing, empty, or unsupported it raises a clear error.
